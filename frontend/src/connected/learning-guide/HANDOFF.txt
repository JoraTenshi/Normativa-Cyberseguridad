Known limits / next integration gates
- This MVP explains sections and lets the user explore them. It does NOT yet
  anchor every nested tab/field, score practical objectives from server receipts,
  or automatically run every subflow of the full application.
- Section readiness is membership/session readiness; nested resource responses
  can be loading, empty or denied. Understood is a user declaration, never proof
  that the resource loaded or the operation was completed.
- On leaving Workspace, organization-specific chapters are hidden until fresh
  membership is available again; their progress is retained, not reset.
- Contextual result/PDS chapters appear on their actual route, not invented IDs.
- Progress does not synchronize across devices/tabs; concurrent same-account
  tabs can overwrite local progress. No credential/security impact; backend CAS
  is a future enhancement. Storage settings/privacy wording should be reconciled
  by the release owner before publishing this new optional storage use.
- Visual proof at mobile/zoom, screen-reader interaction, actual permission changes
  with real API, and integrated selector+guide browser acceptance remain to do.
